# learning-transformers

A structured, coding sandbox dedicated to mastering the Hugging Face 'transformers' ecosystem while maintaining a daily Github contribution streak.

The goal of this repository is to move from high-level pipeline abstractions to fine-tuning custom encoder/decoder models for Natural Language Processing (NLP).

## Learning Objectives
* Master the core Hugging Face libraries: 'transformers'.
* Understand tokenization mechanics(padding, truncation, attention masking).
